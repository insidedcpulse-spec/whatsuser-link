## The CSV format

One contact per line. The first column is a phone number with country code or a WhatsApp username; the optional second column is the pre-filled message.

```
phone,message
351912345678,Hi! I'd like to book a table
5511912345678,Hello, I saw your flyer
joao.silva
```

Rules that avoid problems:

| Rule | Why it matters |
| --- | --- |
| Include the country code | `wa.me` needs the full international number, without `+`, spaces or leading zeros. The generator cleans those for you. |
| Wrap messages containing commas in double quotes | `"Hi, I want the offer"` stays one column. |
| Commas and semicolons both work | Handy for spreadsheets exported in different regions. |
| A header row is optional | Rows like `phone,message` are detected and skipped. |
| Up to 500 rows per file | Split larger lists into several files. |

## Phone numbers vs usernames

Phone-number links (`wa.me/<number>`) work for everyone. Username links (`wa.me/<username>`) only open a chat where WhatsApp's phased username rollout has already arrived, so for printed material prefer phone numbers until your region is live. We explain the current state in [wa.me/username vs wa.me/phone](/blog/wame-username-vs-wame-phone-2026).

## Best practices for printed WhatsApp QR codes

- **Test before printing:** scan one code from each batch with an old and a new phone.
- **Keep contrast and a quiet zone:** dark code on a light background, with blank margin around it. More tips in our [WhatsApp QR code guide](/blog/link-whatsapp-qr-code-gratis).
- **Label what the code does:** "Scan to chat on WhatsApp" gets more scans than a bare code.
- **Use a different message per placement** so you can tell which flyer or table generated the chat.
- **Respect consent:** only message people who contact you or agreed to be contacted. Click-to-chat links are for inbound conversations, not for building unsolicited lists.
