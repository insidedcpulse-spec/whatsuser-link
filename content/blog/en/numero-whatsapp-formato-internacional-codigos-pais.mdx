**Short answer:** for a WhatsApp link, write the number in full international format as **digits only**: country code, then the national number without its leading zero. No `+`, no `00`, no spaces, dashes or brackets. A Portuguese mobile `912 345 678` becomes `351912345678`, and the link is `https://wa.me/351912345678`.

## The rule in four steps

1. Start from the number as people dial it locally, for example `07911 123456` (UK).
2. **Remove** spaces, dashes, brackets, a leading `+` and a leading `00`.
3. **Remove the national trunk zero** at the start of the local number (the `0` in `07911…`).
4. **Add the country code** in front: `44` + `7911123456` = `447911123456`.

The result goes straight into the link: `https://wa.me/447911123456`. Our [free generator](/) does all four steps automatically.

## Common mistakes

- **`+351 912 345 678` pasted as-is.** The plus and spaces must go.
- **Keeping the trunk zero:** `4407911123456` is wrong; use `447911123456`.
- **Forgetting the country code:** `912345678` alone identifies no country, so the chat won't open.
- **Mixing a landline:** the number must be registered on WhatsApp.

## FAQ

**Does wa.me accept the plus sign?** The documented format uses digits only; leave the `+` out.

**What about WhatsApp usernames?** They are a separate, phased feature; see [wa.me/username vs wa.me/phone](/blog/wame-username-vs-wame-phone-2026).

**Can I use the same link for any country?** Yes. The country code inside the number routes it, so one format works worldwide.
